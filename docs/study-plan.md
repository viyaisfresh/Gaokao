## 三、周末 5 小时默认分配

> 共 300 分钟。每周根据当周失分和考试情况动态调整科目。

| 时段 | 时长 | 内容 | 说明 |
|---|---|---|---|
| 30 min | 30m | **复盘诊断** | 把本周错题本过一遍，标出复发 ≥2 次的知识点 |
| 100 min | 1h40m | **第一优先科** | 当前数学（52/150）或物理（42/100），按周轮换 |
| 80 min | 1h20m | **第二优先科** | 当周失分第二多的科目 |
| 60 min | 1h | **优势科巩固** | 化学（65/100）稳分即可，不求突破 |
| 30 min | 30m | **独立复测** | 本周 D7 复测全部走一遍，看 MVP 复测队列 |

### 周末辅导流程（姐姐主导）

1. **周六上午**：学生上传本周试卷照片 + 答题卡 + 标准答案到 MVP（exam analyzer 暂用手动录入）。
2. **周六下午**：姐姐和学生在 MVP 里逐题标错误原因、关联历史错题、识别重复错误。
3. **周六晚**：选出下周最值得攻克的 **3–5 个问题**，写入「明天第一个动作」。
4. **周日上午**：第一优先科训练（100 分钟）。
5. **周日中午**：第二优先科训练（80 分钟）。
6. **周日下午**：优势科巩固 + 独立复测（90 分钟）。
7. **周日睡前**：姐姐在 MVP「评分」页录入本周执行情况，生成评分。

## 七、激励规则

### 现金奖励（主要激励）

| 动作 | 触发条件 | 奖励 |
|---|---|---|
| 上榜 | 周评分 ≥80 | 姐姐定 |
| 加推 | 单科进步 ≥10% | 姐姐定 |
| 里程碑 | 累计掌握 50/100/200 个知识点 | 姐姐定 |
| 复测通过 | D7 复测全通过 | 姐姐定 |
| 费曼完成 | 主动给姐姐讲明白 1 个知识点 | 姐姐定 |

### 评分构成（锁定）

```
总分 = 执行(20%) + 学习效果(30%) + 进步(50%)
学习效果 = 错题复测(40%) + 费曼讲解(20%) + 新题迁移(40%)
进步 = 考试成绩进步(60%) + 知识掌握度(40%)
```

> 评分权重锁死在 `config/scoring.json`，结构可调、权重不可改。
> 激励绑定**结果指标**（完读率、复测通过率），不绑定**行为指标**（发帖数、做题数），防水帖刷量。

## 八、核心陷阱（必须避开）

1. **激励异化**：激励绑完读率等结果，不绑发帖数等行为。
2. **金融合规**：本系统是学习辅导，不涉及荐股，但仍需注意——不写"保证提分 X 分"这类承诺。
3. **头部依赖**：不依赖单次超常发挥，看趋势线。
4. **赋分混算**：录入考试时必须标原始分/等级赋分，禁止混加。
5. **单次波动误判**：单次词汇抽查、单次主观反馈不触发高考预测调整。
